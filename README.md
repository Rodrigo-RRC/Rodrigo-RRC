## 🚀 Projeto em destaque

### 🚘 Detecção de Placas Veiculares Brasileiras — YOLO26s

Fine-tuning do modelo **YOLO26s** para placas brasileiras a partir do dataset **UFPR-ALPR**, com otimização genética de hiperparâmetros e avaliação separada por tipo de veículo. Modelo final publicado no HuggingFace.

📊 **Resultados:** `mAP@50 97,04%` · `IoU 89,74%` · `mAP@50-95 81,70%`
