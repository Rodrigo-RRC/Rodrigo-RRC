<td width="62%" valign="top">

#### 🚘 Detecção de Placas Veiculares Brasileiras

Fine-tuning do **YOLO26s** com o dataset **UFPR-ALPR** em duas etapas: hiperparâmetros manuais (v1) e **busca evolutiva de hiperparâmetros** (v2). Os três modelos foram avaliados no mesmo conjunto de teste, com notebooks reproduzíveis.

**Ganho sobre o modelo base (mAP@50-95):**<br>
`60,24%` ➜ **`82,03%`**

[![Testar online](https://img.shields.io/badge/▶_Testar_online-FF6F00?style=for-the-badge&logo=huggingface&logoColor=white)](https://huggingface.co/spaces/RodrigoRRC/deteccao-placas-br)
[![Repositório](https://img.shields.io/badge/Repositório-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Rodrigo-RRC/license-plate-br-yolo26s-finetuning)
[![Modelo](https://img.shields.io/badge/Modelo-FFD21E?style=for-the-badge&logo=huggingface&logoColor=black)](https://huggingface.co/RodrigoRRC/license-plate-br-yolo26s)
